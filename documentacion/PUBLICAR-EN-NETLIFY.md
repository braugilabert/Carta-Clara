# Publicar Carta Clara en Netlify

La versión lista para Netlify está en la carpeta `dist/`. Incluye la página principal, las nueve muestras, logos, favicon, imágenes y recursos.

## Opción rápida: compartirla hoy

1. Abre [Netlify Drop](https://app.netlify.com/drop).
2. Arrastra la carpeta completa `dist/` a la zona de publicación.
3. Netlify mostrará una URL terminada en `netlify.app`.
4. Copia esa URL y envíasela a tu amigo.

No necesitas crear un repositorio ni instalar herramientas para esta primera prueba. La carpeta debe subirse completa; no arrastres solamente `index.html`.

## Opción estable: conectarla a GitHub

Si subes este proyecto a GitHub, en Netlify elige importar el repositorio. El archivo `netlify.toml` ya indica que la carpeta publicada es `dist`.

Con GitHub conectado, cada actualización que hagas en el repositorio puede generar una publicación nueva de forma automática.

## Antes de compartir ampliamente

La web contiene muestras ficticias y no incluye todavía un correo o formulario de contacto real. Consulta [PUBLICAR-WEB.md](PUBLICAR-WEB.md) para completar los datos y textos pendientes antes de usarla comercialmente.
