# Copies para el lanzamiento

## 01 — Radar

**Instagram:** No necesitas más enlaces guardados. Necesitas saber cuáles merecen cinco minutos de tu tiempo. Radar es una muestra de newsletter para seguir un sector con contexto, fuente y una idea clara. `#newsletter #profesionales #contenidos`

**YouTube:** Cómo crear un resumen sectorial que no parezca una lista de enlaces.

## 02 — Aula

**Instagram:** Aprender no siempre pide una hora libre. A veces basta una explicación, tres ejemplos y un reto corto. Así podría acompañar una newsletter a una academia.

**YouTube:** Una newsletter para alumnos: ejemplo, estructura y frecuencia.

## 03 — Entrena

**Instagram:** La constancia también se entrena. Una idea sencilla para la semana puede ayudar a volver con intención, no con culpa. Ejemplo ficticio de Carta Clara.

**YouTube:** Qué enviaría en la newsletter de un centro deportivo.

## 04 — Idioma en marcha

**Instagram:** Una expresión. Un contexto. Un minuto de práctica. El idioma se queda cuando encuentra un hueco real en la semana.

**YouTube:** 3 secciones para una newsletter de idiomas que se abra de verdad.

## 05 — Equipo al día

**Instagram:** No toda actualización necesita una reunión. Una lectura breve puede dejar claro qué cambia, qué importa y qué viene después.

**YouTube:** Cómo ordenar las novedades de un equipo sin llenar el chat.

## 06 — Pausa

**Instagram:** La bandeja de entrada también puede ser un sitio al que apetece volver. Una lectura, una idea y una pregunta para terminar el día con algo más que prisa.

**YouTube:** Diseñar una newsletter personal que no sea otro ruido más.

## Llamadas a la acción reutilizables

- ¿Qué tres secciones tendría la tuya?
- Guarda esta idea para diseñar tu próxima edición.
- ¿A quién le enviarías una lectura así?
- Si quieres una muestra, empieza por contarme para quién es.
